\begin{frame}{The SPNE}
The SPNE is fully specified by giving the probability of every action at \textbf{every} decision node:
\bsk
\centering
Michigan: \ $\sigma_1^*=\beh[cc|cc]{\text{Kick} & \text{GoFor2} & \text{Run} & \text{Pass}}{\underline{\hspace{0.3in}} & \underline{\hspace{0.3in}} & \underline{\hspace{0.3in}} & \underline{\hspace{0.3in}}}$
\qquad
OSU: \ $\sigma_2^*=\beh{\text{SR} & \text{SP}}{\underline{\hspace{0.3in}} & \underline{\hspace{0.3in}}}$
\bsk
\raggedright
\only<2->{\textbf{Notice:} we didn't write a probability for each \textbf{strategy}\\
We wrote one probability distribution per \textbf{information set}\\}
\only<3->{\bsk That's called a \textbf{behavioral strategy}}
\vspace{-0.3in}
\end{frame}


\begin{frame}{Selten's Theorem}
\begin{block}{Theorem (Selten, 1965)}
Every finite extensive-form game with cardinal payoffs has \textbf{at least one} SPNE (possibly involving mixed strategies).
\end{block}
(\textbf{Finite game:} Finite \# players, finite \# of actions, tree doesn't go forever.)
\bsk
Why?
\begin{itemize}
    \item Every subgame is a finite game
    \item Nash: every finite game has a (mixed) NE
    \item So the SPNE algorithm can give a prediction at every subgame
    \item And the game is finite, so the algorithm doesn't run forever
\end{itemize}
\vfill
{\footnotesize Reinhard Selten shared the 1994 Nobel Prize with John Nash and John Harsanyi.}
\vspace{-0.2in}
\end{frame}

\begin{frame}{Michigan's Strategies}
A strategy: one choice at every information set (Chapter 4)
\bsk
Michigan has two information sets, two choices each:
$$S_{MI}=\{\ (\text{Kick},\text{Run}),\ (\text{Kick},\text{Pass}),\ (\text{GoFor2},\text{Run}),\ (\text{GoFor2},\text{Pass})\ \}$$
\vspace{-0.1in}
\begin{itemize}
    \item (Kick, Run) and (Kick, Pass) are different strategies, even though Kick precludes the Run/Pass decision.
\end{itemize}
\bsk
Mixed strategy (Chapter 6): a probability for each of the 4 strategies
$$\begin{pmatrix} (\text{Kick},\text{Run}) & (\text{Kick},\text{Pass}) & (\text{GoFor2},\text{Run}) & (\text{GoFor2},\text{Pass}) \\ p & q & r & 1-p-q-r\end{pmatrix}$$
\vspace{-0.1in}
\begin{itemize}
    \item Needs \underline{\hspace{0.4in}} numbers
\end{itemize}
\vfill
\vspace{-0.3in}
\end{frame}

\begin{frame}{Formal Definition: Behavioral Strategy}
\begin{block}{Definition (Bonanno 7.1.1)}
A \textbf{behavioral strategy} for a player is a list of probability distributions, one for every information set of that player. These give the probability the player plays each action at each information set.
\end{block}
\bsk
\vfill
\onslide<3->{\textbf{Fact:} If a player has only one information set then mixed $=$ behavioral (like OSU)}
\vspace{-0.3in}
\end{frame}

\begin{frame}{Are They the Same?}
Suppose Michigan's coach uses this mixed strategy:
$$\sigma_1=\begin{pmatrix} (\text{Kick},\text{Run}) & (\text{Kick},\text{Pass}) & (\text{GoFor2},\text{Run}) & (\text{GoFor2},\text{Pass}) \\ 0.1 & 0.3 & 0.36 & 0.24\end{pmatrix}$$
\bsk
Find a behavioral strategy that does the same thing:
\bsk
Pr(Kick) $=$ \underline{\hspace{1in}}\quad Pr(GoFor2) $=$ \underline{\hspace{1in}}
\bsk
Pr(Run $\mid$ GoFor2) $=$ \underline{\hspace{1in}}\quad Pr(Pass $\mid$ GoFor2) $=$ \underline{\hspace{1in}}
\bsk
\only<1>{\textbf{Notation}: Pr(A $\mid$ B) means ``Probability of A, given $B$ already occurred.''\\This is called a \textit{conditional probability}.}
\onslide<2->{Check: Pr(GoFor2 and Run) $=$ \underline{\hspace{1.2in}} \ $=0.36$ \ \checkmark}
\vfill
\onslide<3->{\textbf{Lesson:} The 0.1 vs.\ 0.3 split never matters. The behavioral strategy doesn't require it.}
\vspace{-0.3in}
\end{frame}

\begin{frame}{Kuhn's Theorem}
\begin{block}{Theorem (Kuhn, 1953)}
In games with \textbf{perfect recall}, for every mixed strategy there is a behavioral strategy that gives the same probability over terminal nodes
\end{block}
\bsk
Recall perfect recall (Chapter 4):
\begin{itemize}
    \item Never forget what you knew
    \item Never forget what you did
\end{itemize}
\bsk
\textbf{Takeaway:} Use behavioral strategies. They're simpler, and nothing is lost
\bsk
\textbf{Notation:} We'll use $\sigma_i$ to describe either a mixed or behavioral strategy
\vfill
{\footnotesize Bonanno works through his own example (Figure 7.3) on pp.~239--241.}
\vspace{-0.2in}
\end{frame}

\begin{frame}{Two Ways To Be Unpredictable}
Randomize \textbf{as you go} (behavioral):
\begin{itemize}
    \item \textbf{Play-calling}: each down, run or pass?
    \item \textbf{Pitching}: each pitch, fastball or curveball?
    \item \textbf{Poker}: each betting round, bluff or fold?
    \item \textbf{Penalty kicks}: each kick, left or right?
\end{itemize}
\bsk
Randomize \textbf{a whole plan in advance} (mixed):
\begin{itemize}
    \item \textbf{Security}: LAX's ARMOR software draws each day's checkpoint schedule
    \item \textbf{Inspections}: random drug-test lists, tax audits, restaurant inspections
    \item \textbf{Exams}: a random version of the test, handed out before it starts
\end{itemize}
\bsk
Kuhn: with perfect recall, the two are equally powerful
\vfill
%{\footnotesize Not in the book. ARMOR: Pita et al.\ (2008, AAMAS).}
\vspace{-0.2in}
\end{frame}

\onslide<4->{\textbf{Problem:} Player 3's info set isn't the root of a subgame. In this SPNE it's never reached, so anything is a best reply}

\begin{frame}{So What's Missing?}
SPNE checks for rationality only in \textbf{subgames}
\begin{itemize}
    \item A subgame can't cut an information set
    \item Maybe that's not strict enough?
\end{itemize}
\bsk
The fix: Check that strategies are rational at \textbf{every} infoset (not just subgames)
\bsk
\textbf{Goal:} \ $\{\text{better solution concept}\}\subseteq SPNE\subseteq NE$
\bsk
\textbf{Coming in Chapter 11:} a new solution concept that fixes this
\begin{itemize}
    \item \textbf{Weak sequential equilibrium}: give P3 a \textbf{belief} about where she is
\end{itemize}
\vfill
{\footnotesize Another fix: \textbf{trembling-hand perfect equilibrium} (Selten, 1975). Not covered in this class.}
\vspace{-0.2in}
\end{frame}

\begin{frame}{What Have We Learned, Charlie Brown?}
\begin{itemize}
    \item Nature in a tree? Replace the lottery with its \textbf{expected utility}
    \item \textbf{Behavioral strategy}: one probability distribution per information set
    \begin{itemize}
        \item Mixed: spin one wheel over whole plans. Behavioral: flip as you go
    \end{itemize}
    \item \textbf{Kuhn (1953)}: with perfect recall, behavioral $=$ mixed
    \item \textbf{Selten (1965)}: with cardinal payoffs, a SPNE always exists
    \begin{itemize}
        \item Solve subgames with mixed NE when there's no pure one
    \end{itemize}
    \item SPNE can still allow silly choices at unreached infosets (Selten's horse)
    \item The fix comes in Chapter 11: weak sequential equilibrium
\end{itemize}
\vfill
\vspace{-0.4in}
\end{frame}
